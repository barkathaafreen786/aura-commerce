# Adaptive Retail Intelligence (ARI) Platform

This repository contains the MVC-style application scaffold for the Adaptive Retail Intelligence Platform MVP.

## Folder Structure

- `/backend` - Node.js/Express API Gateway and core services matching our microservice pattern logic.
- `/frontend` - Vite/React web dashboard for retail analytics and rule management.
- `/docs` - Placeholder for expanded technical documentation.

## Running Locally

### Backend
```bash
cd backend
npm install
node server.js
```
Runs on `http://localhost:5000`

### Frontend
```bash
cd frontend
npm run dev
```
Runs on `http://localhost:5173`

For detailed technical specifications, refer to the `ARI_Technical_PRD.md` document provided by your engineering lead.
